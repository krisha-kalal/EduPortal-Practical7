# EduPortal — Automated Student Information & Learning Management System

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![Build Status](https://img.shields.io/badge/build-passing-brightgreen)
![License](https://img.shields.io/badge/license-MIT-green)

EduPortal is a web-based educational management platform designed to streamline student course enrollment, online exam processing, and academic tracking.

---

## 🚀 Key Modules
* **User Authentication & Authorization:** Secure JWT-based login for Students, Faculty, and Administrators.
* **Course Catalog & Enrollment:** Real-time seat tracking, prerequisite checking, and automated registration.
* **Online Examination Engine:** Automated time tracking, dynamic question delivery, and submission validation.
* **Grade Management:** Real-time transcript updates and performance reporting.

---

## 🛠️ Technology Stack
* **Frontend:** HTML5, CSS3, JavaScript (React / Tailwind CSS)
* **Backend:** Node.js, Express.js
* **Database:** PostgreSQL
* **Version Control & CI/CD:** Git, GitHub, GitHub Actions
